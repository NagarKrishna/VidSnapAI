VidSnapAI – AI Reel Generator:
VidSnapAI is a Python and Flask-based web application that automatically creates short-form videos using uploaded images and AI-generated voice narration.
Features:
Upload multiple images to create reels.
Convert text into speech using ElevenLabs AI.
Automatically generate videos using FFmpeg.
Generate vertical videos (1080 × 1920).
View generated videos in a gallery.
Tech Stack:
Backend: Python, Flask
Frontend: HTML, CSS, JavaScript, Bootstrap
AI Integration: ElevenLabs API
Video Processing: FFmpeg
Version Control: GitHub
